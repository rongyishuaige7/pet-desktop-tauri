# 桌宠可靠性修复

范围：修复审查中复现的活动宠物竞争、删除非活动项、播放器末帧、失败恢复、取消及素材校验问题；保留现有重命名和帧资源补全能力。不更换框架，不升级现有依赖，不改在线服务配置。

## 设计

- IndexedDB 将保存资料与激活分开，动作更新只修改已有宠物；所有事务处理 complete/error/abort，并关闭连接。列表通知只广播变更信号，接收端重新读取。
- 工作室统一初始化、串行化激活和删除，切换期间忽略旧动作事件；更新 ref 与 React 状态同时完成。列表使用缩略图，完整帧仅在激活时加载，缺失素材显示错误并保留当前宠物。
- 桌面模式由 Rust 决定动作结束；两个平台共享可用假时钟测试的播放状态机。素材先解码验证再替换，失败保留旧帧。内置包持久化逻辑路径，用户素材保留绝对路径。
- AI 在异步边界复核取消；切片做基础尺寸和透明主体校验；失败保留可重试的阶段结果，不记录密钥。
- AI 网络请求复用 HTTP 连接，流式读取时限制响应体积；下载和参考图按实际格式解码验证，错误不携带原始响应或签名 URL，不再落盘完整服务响应。

## 风险与验证

保留旧数据库结构和旧接口兼容，避免丢失已有宠物。跨 IndexedDB / 原生运行时的切换无法使用单个事务，故准备完成后提交，失败需回退。原生 AppKit / GTK 的线程限制保持原样。

验证包括：真实 IndexedDB 的多宠物 CRUD、事务故障、重命名和动作并发；隔离浏览器的切换事件、启动恢复、删除、错误反馈及跨页同步；Rust 播放暂停/末帧/帧率、素材格式及路径测试；TypeScript、前端构建、macOS Rust 检查和 CI 的 Linux 检查。不调用真实付费 AI。

## 分批交付

1. 工作室状态、资源加载、数据库和交互修复；验证后提交并推送。
2. 原生共享播放器、路径与素材安全替换；验证后提交并推送。
3. AI 取消与质量检查、帧包工具和补充回归；验证后提交并推送。

各批验证结果随交付更新。

## 复核修复（2026-10-22）

针对 `c94d5b9` 复核记录的 7 项问题：

1. 命令回复统一走 client 的 `session/revision` 合并，hook 不再直接写入原始回复；新增旧回复落后于事件的流程。
2. 删除当前伙伴只替换素材，不再发送 `show`；隐藏/休息意图和到期时刻保留，新增隐藏、休息两种删除流程。
3. 新增 `claimAdoptionRecord` 单事务领取/复用 adoption 与 pending id；`commitAdoptedPet` 在同一事务复核 pending id、已提交记录和活动指针，双窗口只产生一条资料。
4. 新领养清空旧 `confirmedPetId`；恢复判断在 `prepared/committed` 阶段优先 pending id，旧伙伴不会变成新草稿的见面页。
5. 显示命令失败后进入“资料已保存，等待显示”状态，不再弹入住成功；“重试显示”只重发显示命令，完成见面被阻止。
6. `refresh` 会复用或补建事件订阅、标记 ready、重放缓存事件并合并当前快照；hook 清除连接错误并恢复 connected。
7. 网页自主活动只由适配层状态驱动，复选框、localStorage 和浏览器调度共用同一值。

验证（本轮修复后）：93 项前端单元测试、33 项 Rust 测试、42 个隔离浏览器流程（原 34 个 + 复核 8 个）、生产构建通过；二次复核随后再补 4 个流程。仍待真实桌面验收。

4. 网页自主调度改用 `effectiveAutonomous`，隐藏、暂停、低动态时清理定时器，并在回调执行前复查最新状态。

## 第三次复核修复（2026-10-22）
