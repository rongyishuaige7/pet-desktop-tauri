# 桌宠可靠性修复

范围：修复审查中复现的活动宠物竞争、删除非活动项、播放器末帧、失败恢复、取消及素材校验问题；保留现有重命名和帧资源补全能力。不更换框架，不升级现有依赖，不改在线服务配置。

## 设计

- IndexedDB 将保存资料与激活分开，动作更新只修改已有宠物；所有事务处理 complete/error/abort，并关闭连接。列表通知只广播变更信号，接收端重新读取。
- 工作室统一初始化、串行化激活和删除，切换期间忽略旧动作事件；更新 ref 与 React 状态同时完成。列表使用缩略图，完整帧仅在激活时加载，缺失素材显示错误并保留当前宠物。
- 桌面模式由 Rust 决定动作结束；两个平台共享可用假时钟测试的播放状态机。素材先解码验证再替换，失败保留旧帧。内置包持久化逻辑路径，用户素材保留绝对路径。
- AI 在异步边界复核取消；切片做基础尺寸和透明主体校验；失败保留可重试的阶段结果，不记录密钥。

## 风险与验证

保留旧数据库结构和旧接口兼容，避免丢失已有宠物。跨 IndexedDB / 原生运行时的切换无法使用单个事务，故准备完成后提交，失败需回退。原生 AppKit / GTK 的线程限制保持原样。

验证包括：真实 IndexedDB 的多宠物 CRUD、事务故障、重命名和动作并发；隔离浏览器的切换事件、启动恢复、删除、错误反馈及跨页同步；Rust 播放暂停/末帧/帧率、素材格式及路径测试；TypeScript、前端构建、macOS Rust 检查和 CI 的 Linux 检查。不调用真实付费 AI。

## 分批交付

1. 工作室状态、资源加载、数据库和交互修复；验证后提交并推送。
2. 原生共享播放器、路径与素材安全替换；验证后提交并推送。
3. AI 取消与质量检查、帧包工具和补充回归；验证后提交并推送。

各批验证结果随交付更新。

## 第一批验证

- 36 项单元测试通过，包含 IndexedDB 中止回滚、非活动项删除、并发重命名/动作和延迟事件。
- TypeScript 与 Vite 生产构建通过。
- 隔离 Chrome / 模拟 Tauri IPC 的 10 个流程通过：删除、跨页同步、缺失素材、切换事件竞争、原生播放权威、启动动作恢复、按钮颜色、按需加载、部署失败保留旧宠物、空集合重启。
- 浏览器回归入口：`tools/verify-workflows.mjs`。用独立安装的 playwright-core，设置 `PET_PLAYWRIGHT_MODULE`、`PET_EVIDENCE_DIR`，可选 `PET_CHROME_PATH` / `PET_PREVIEW_URL`。只允许本机预览，不接触真实浏览器资料或在线 AI。

## 第二批验证

- 22 项 macOS Rust 测试、文档测试及 cargo check 通过；播放器覆盖末帧、暂停、时间余量及同动作重播，素材测试覆盖伪造图片、尺寸限制、已有目录保护和无效包保留原选择。
- 原生事件携带 petId / revision，命令回复确认动作；UI 拒绝旧宠物和旧版本事件。删除最后一个宠物会隐藏原生窗口，并保留空集合状态。
- 内置素材保存 `./frame-pack`，迁移旧应用包绝对路径；用户目录不自动替换。原生解码后整体替换，非正方素材掩码保留原始比例。
- 图片上限：单图 16 MiB / 2048×2048，每动作 5–60 帧，帧包文件总量 128 MiB / 解码总量 256 MiB。保存只创建新目录，不覆盖已有包。
- 36 项前端测试、生产构建和 12 个隔离浏览器流程通过。Rust 验证使用独立 CARGO_TARGET_DIR，避免与现有 tauri dev 共享产物；未停止既有开发服务。
- Linux 编译与测试由本批推送触发的 CI 验证；桌面实机操作不以模拟 IPC 代替验收。
