# 桌面贴贴宠物 · 使用说明

1. 打开应用，左侧三个页签：互动伴侣台、宠物工坊、我的宠物架。
2. 先去「宠物工坊」：填名字、选猫狗；输入帧包目录点「一键导入」，或给六个动作各传至少 5 张图再保存，也可用照片让 AI 生成。
3. 回「互动伴侣台」点按钮切换待机、坐下、睡觉、开心、走路、跳跃，拖滑块调大小；Mac 可「叫回右下角」。
4. 网页预览时，右侧「显示与姿态」里的「自主活动」默认开启，宠物会自己溜达、坐下、打盹；不想让它乱跑就点成「原地待命」。
5. 「宠物架」里点「派去桌面」换宠物，点 🗑️ 删除。
6. 桌面宠物可拖动、右键换动作，关掉主窗口它仍在。
7. 用托盘图标暂停、重置或退出。
