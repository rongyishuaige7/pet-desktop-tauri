# 首版验收清单

对应 [产品规格](v0.2-prd.md) 与 [工程说明](v0.2-engineering.md)。实现提交 `cce04a1`，2026-10-22 已按 S01–S05 实施结果核对：自动化覆盖项见第 6 节；第 5 节桌面实机项仍为待验收，浏览器模拟 IPC 不能代替真实桌面操作。第 1–4 节保留原始验收条目，逐项结果与证据见第 6 节。

## 1. 首次体验与迁移

- [ ] A01 干净安装：不读文档可选择咕唧、起名并入住；成功后只有一条宠物记录，名字和素材正确。
- [ ] A02 老版本已有宠物：升级后直接恢复原伙伴、名字、素材和配置，不强制领养、不新增默认角色。
- [ ] A03 老用户主动清空：升级/重启后仍为空，不出现强制引导或自动补回宠物。
- [ ] A04 领养提交中双击或同时打开第二窗口：最终只有一条记录；确认后的刷新失败只重新读取。
- [ ] A05 引导在选择/命名/见面各阶段刷新：恢复正确步骤；已提交伙伴不重复创建。
- [ ] A06 领养保存失败：名字与选择保留，原生旧伙伴回滚，重试成功后不留两个活动 id。
- [ ] A07 用户跳过教学：可正常进入陪伴；之后从帮助重新查看。中文输入法 Enter 不提前提交。
- [ ] A08 在准备记录后、原生确认后、资料提交后分别刷新/退出：恢复同次领养，不重复创建；未提交伙伴不被当成已入住。
- [ ] A09 旧库存在 current 资料但缺初始化标记：仍按老用户恢复；数据库读取失败时提供重试，不启动全新领养。

## 2. 显示与控制

- [ ] B01 主界面修改暂停、自主活动、比例：原生与托盘一致；托盘修改后主界面及时一致。
- [ ] B02 暂停预览：只暂停页面；暂停桌宠：真实桌面停止，当前画面保留，自主调度停止。
- [ ] B03 暂时收起：窗口隐藏，资料保留；关闭/重开主窗口和重启应用后仍隐藏。
- [ ] B04 唤回：当前伙伴出现，原位置与比例保留，从当前动作首帧开始；显式暂停仍然保持。
- [ ] B05 休息一小时：窗口隐藏，显示到期时间；提前唤回清除计时，到期不再次改变状态。
- [ ] B06 休息期间重启：未到期保持隐藏，到期后仅恢复当前健康伙伴。
- [ ] B07 系统睡眠跨越到期：唤醒后检查一次，不重复触发、不消耗整段休息作为帧播放时间。
- [ ] B08 休息期间删除全部伙伴：到期后仍为空，不恢复旧角色；手动派新伙伴去桌面则清除旧计时。
- [ ] B09 休息期间改为手动隐藏：计时清除，原到期时间不再唤回。
- [ ] B10 启动加载素材、跨页通知和后台资料补全：不把 hidden/snoozed 改回 shown。
- [ ] B11 减少动态效果：主窗口关闭后原生也保持静态；用户原暂停/自主偏好不丢失；关闭低动态后按原偏好恢复。
- [ ] B12 不支持的穿透/位置/系统动态偏好：按能力显示说明，不出现可点击空操作。
- [ ] B13 自启失败或原子写入失败：勾选回到已确认值，错误保留可重试；其他功能继续使用。
- [ ] B14 快速连续操作、旧事件、旧进程会话与旧平台回调：不覆盖新状态或新伙伴。

## 3. 互动

- [ ] C01 主界面摸摸头、打招呼和桌面主体单击：播放对应反馈，结束返回原有 idle 规则。
- [ ] C02 同一伙伴从不同入口在 1.5 秒内重复互动：只接受一次，不刷通知、不叠加动画。
- [ ] C03 拖拽超过 3pt 后释放：只移动，不触发单击反馈；右键也不触发摸摸头。
- [ ] C04 隐藏/休息/显式暂停/资源未就绪：不被互动偷偷唤醒或恢复播放，按钮有正确说明。
- [ ] C05 低动态下互动：仍可收到文字确认，不启动动作；切换伙伴后旧 petId 互动被拒绝。

## 4. 页面、错误与保留能力

- [ ] D01 当前状态真实：网页标注演示；加载、隐藏、休息、暂停和错误有不同文案，不固定显示“在线”。
- [ ] D02 素材缺失：持续错误可重试、换已有伙伴或进入制作；错误不因 Toast 消失而无处恢复。
- [ ] D03 新伙伴部署失败：原伙伴正常活动，旧 id/帧保持，错误针对本次失败操作。
- [ ] D04 原有本地导入、手动装配、AI、重命名、切换和删除均可到达；AI 会话内续传和保存期间取消仍通过。
- [ ] D05 明确操作意图：保存并入住/派去桌面会显示；单纯恢复页面或刷新列表不会显示隐藏伙伴。
- [ ] D06 抽屉和教学可全键盘操作，焦点受限、Escape 可关闭并还原；输入有标签，图标有名称。
- [ ] D07 840×620 和 1120×760 无横向溢出，主要操作可滚动到达；按钮文本对比度和焦点可见性合格。
- [ ] D08 错误复制内容、引导记录和普通日志无 API Key、照片、私有 URL 或完整服务响应。
